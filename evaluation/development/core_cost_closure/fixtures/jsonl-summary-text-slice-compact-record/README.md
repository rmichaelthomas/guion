# JSONL summary: compact typed aggregate

This fixture is a separately labeled, idiomatic version of the frozen JSONL summary application. The frozen source remains unchanged at `evaluation/completion/applications/jsonl-summary/main.vr` and stays the reference lane for runtime comparisons.

The variant keeps the existing timestamp parser and UTC formatter. It obtains the date with `text_slice(at, 0, 10)` from the formatter's canonical timestamp, and stores each service/date aggregate as an `EventSummary` containing a count and the earliest/latest Unix-microsecond values. It materializes the report's JSON fields once, when producing the final output. This avoids repeatedly updating JSON objects while preserving the output schema.

The source is generated by the `text-slice-and-compact-record` transformation in `evaluation/development/core_cost_closure/benchmark_jsonl_source_variant.py`. The paired benchmark checks every result against both Python and SQLite references and records the exact source hashes and peak RSS. See `evaluation/development/core_cost_closure/results/jsonl-text-slice-and-compact-record-paired-15.json` and the later parser-fast-path comparison for measurements. This is an application-level improvement; it does not establish that the Guion runtime itself is as fast as Python.
