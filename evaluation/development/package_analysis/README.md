# Package-backed analysis

This retained Veritas-format prototype transfers a JSON document through Guion's typed Python bridge to `orjson` and NumPy, computes count/total/min/max/mean over a large integer column and configurable string grouping, and atomically writes JSON that another program can consume. Values must be signed 64-bit integers for NumPy array analysis; the total uses Python's arbitrary-precision integers. It is designed to expose the real costs of dependency setup, JSON transfer, native wheels, repeated invocation, and same-host relocation. The standard-library Python reference performs the same observable operation.

The older acceptance workload generates its data rather than embedding expected results in the app. It compares report bytes and console output, repeats the analysis, then bundles the compiled wheels and runtime, relocates the source-free package, and executes it without an external Python environment. That managed install and relocation path has not been rerun against current artifact format 44. The current Guion bridge result and its limits are in the [2026-10-27 report](../../completion/results/real-task-sprint/2026-10-27-python-bridge-package-analysis.md); its [reproducible timing runner](../../completion/performance/benchmark_python_package_analysis.py) uses an explicit installed interpreter and does not claim managed-package or relocation coverage.
