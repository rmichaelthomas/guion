# Independent v1 campaign record

This directory preserves the first frozen candidate packet and its compact setup evidence. Its `freeze-record.json` says the packet was invalidated by pilot revisions before formal collection. Treat it as a superseded campaign setup, not as a scored recommendation or build study.

The retained `schedule.json`, `freeze-record.json`, and `choice-evidence/` files are historical inputs and records. They do not establish a valid final outcome for the revised candidate. The later valid blinded recommendation results are indexed in [independent v3](../independent-v3/README.md); independent v2 records its own partial format-30 sessions and has no official choice outcomes.

The files in this directory remain unchanged. This README is a navigation note added during the Guion migration to clarify the campaign's status.
