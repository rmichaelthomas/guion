# Guion first-source speed — 2026-10-25

**Revision:** `7a909f7681cfa98a3c5f63ad9c7539da688402d8`

**Machine:** Darwin arm64; Python 3.14.7

## What changed

Normal source compilation now uses Guion’s in-process Rust compiler. Users do not need Rust or a separate compiler installed. The Guion-written compiler remains in the repository and its bootstrap/parity checks still pass. The compiler build fingerprint is part of the source-cache identity.

## Fresh source-run results

**All five short-workload gates passed:** every paired median ratio and every 95% interval upper bound was below 1.0. ## What this does and does not establish

- This is strong evidence that Guion’s first source run now beats Python on these five small, practical tasks on this macOS arm64 machine.
- It does not establish that Guion is faster than Python in general, across platforms, or across all kinds of programs.
- The earlier six-workload installed-release report remains historical. This pass did not rerun its two parallel-CPU cases or its 20,000-row JSONL case; new short tests separately exercise JSON-file and SQLite/TOML paths.
- The OS file cache was uncontrolled. These are no-source-cache runs, not cold-disk measurements.
- Peak memory is unavailable: the OS denied the existing sampler. No permission escalation or repeat attempt was made.
