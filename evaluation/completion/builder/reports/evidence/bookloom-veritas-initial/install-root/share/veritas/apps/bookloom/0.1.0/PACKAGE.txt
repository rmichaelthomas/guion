Veritas application package

Run with: ./run [arguments]
Check it with: ./veritas verify-package .
Set VERITAS_VERIFY_PACKAGE=1 to make the launcher verify the package before running. Full verification hashes the bundled runtime, resources, Python environment, and native images, so it can add noticeable startup time for large bundles. Verification hashes detect accidental corruption; they do not authenticate the publisher. The package contains a source-free Veritas artifact, the matching host runtime, its project policy, and the resources listed in veritas.toml [package].resources. NATIVE-DEPENDENCIES.json records macOS Mach-O dependencies and wheel images; linux-dependencies.json records Linux ELF dependencies, runtime resolutions, and required glibc versions. Both reports include architectures, hashes, and available distribution provenance. Python-assisted projects also include pinned managed CPython, uv, locked bridge project, offline dependency cache, Python distribution metadata, and CPython/uv/Tcl/Tk license notices. Prepared Veritas distributions also contribute target-specific Rust dependency inventory and license files. The inventory does not assess legal compatibility. On macOS, `veritas run --json` reports newly resident native images loaded by Python calls; transient loads between snapshots may not appear. The package is verified for macOS ARM64 or Debian 12-compatible GNU/Linux ARM64 with glibc. Run it on its named target; other operating systems, architectures, Linux distributions, and libc implementations are unverified.
