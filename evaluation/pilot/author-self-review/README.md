## Findings that affect the shared build

1. **The task runner's candidate directory is not the guest's working directory.** Veritas defaults file access to the project root, while task fixtures and expected artifacts live at the runner workspace root. Added opt-in `workspace_root_project` staging so the candidate project and fixtures share the fresh workspace without a task-specific launcher. It is covered by a regression test and documented for the campaign.
2. **There was no native stderr operation.** Added `eprint`, a distinct `ProgramErrorOutput` effect, separate capture in runtime/CLI JSON, combined output-limit enforcement, and artifact format 28. Runtime and CLI regression tests pass.
3. **HTTP timeout was project-wide, not request-specific.** Added `http_request_with_timeout`; its effective deadline is capped by manifest `HostPolicy`, and the operation requires artifact format 27. The full HTTP runtime test module passes, including both a shorter requested timeout and a caller request that attempts to exceed the host ceiling.
4. **The config migrator uses comment-preserving TOML.** It uses a declared, locked `tomlkit` dependency through the managed bridge; macOS and Debian 12-compatible Linux ARM64 packaging, relocation, and source-free use are verified. The side-by-side dependency size/startup comparison remains.

This checkpoint is an evidence check, not a release candidate or a stop for user approval.
5.
