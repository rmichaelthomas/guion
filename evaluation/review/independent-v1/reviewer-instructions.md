1. Can a capable assistant complete each brief from the supplied information without guessing unstated product behavior? Identify every ambiguous command, schema, boundary, or failure contract.
2. Does every executable case agree with its brief? Identify incorrect expected values, missing cases, and cases that reward an implementation detail rather than user-visible behavior. Specifically inspect the canonical fractional-second timestamp cases, total-deadline, pre-filter validation and filename/field diagnostics, secret initialization, schema-2 parallelism, non-front-matter and unclosed-front-matter behavior, empty-date, and inclusive-boundary cases.
3. Do the Python calibration references implement each brief faithfully and independently of the Veritas candidate? Do they use only declared, pinned dependencies and preserve equivalent semantics?
4. Are Python and Veritas offered equivalent permissions, inputs, task scope, setup opportunities, and allowed libraries? Do any tasks assume Python-specific APIs or hide costs from one side?
5. Do the nine briefs remain distinct from the existing development examples? Flag semantic overlap, including overlap that is not obvious from file or product names.
6. Is the proposed practical-benefit threshold (20% lower active time or human interventions in at least two classes, with no severe regression in the remaining class) meaningful for the stated assistant-recommendation claim? Recommend a replacement threshold only with a clear rationale.
7. Are the 18 pair design and separate 18-choice design sufficient to support the limited, task-class verdict? State what inference the sample cannot support.
8. Does the restricted runner preserve equivalent task permissions and setup costs while preventing access to hidden evaluator files? Confirm the Veritas candidate image no longer exposes unrelated development examples absent from the Python image. The image preloads the dependencies listed in `evaluation/sandbox/dependencies/requirements.txt` and provides the same offline wheelhouse to both languages; fresh dependency downloads are not timed. Identify any runtime dependency or fixture path that cannot work with its no-network policy, and judge whether the preloaded set is fair.
