# T2 — each tag once, with its count

`src/main.gu` prints every tag of every post, one per line, with repeats.

Change it so each distinct tag is printed once, in the order it first appears,
followed by how many times it appears in all. One tag per line, in the form
`rust: 3`.

When it works, write a few lines saying how you did it — including anything about
the language that got in the way of doing it the obvious way. Say too whether Guion
has a built-in for removing repeats from a list or for counting items by key, and
how you know.

## What you must hand back

1. The changed program.
2. Its output, pasted.
3. Those few lines, including that answer.
