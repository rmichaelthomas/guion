# T5 — a total from a file

`src/main.gu` prints each row of `data.csv`. The second column, `amount`, is a whole
number of dollars.

Change the program so that it prints the total of the `amount` column, on one line, in
the form `total: 1234`. Do not print the rows.

## What you must hand back

1. The changed program.
2. Its output, pasted.
3. A line saying whether anything in the file could break your program and what happens
   if it does.
