# T4 — what can it touch

You are about to run `src/main.gu` on a machine that matters. Do not run it.

Say what this program can do to the machine and to the network, and which function
does each thing. Say how sure that statement is and what it is not a guarantee of.

## What you must hand back

1. For each function that does anything outside the program's own memory: its name and
   what it can reach.
2. The command or commands you used to find this out.
3. One sentence on what your answer does not guarantee.
