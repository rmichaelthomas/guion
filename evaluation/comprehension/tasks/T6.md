# T6 — first program, from the website

You have heard of Guion. You have two things and nothing else: the text of its website
(`{{ROOT}}/site/`, one file per page) and the download the website's Download button gives
you (`{{ROOT}}/download/`). You have not seen the language before.

On this machine, get a Guion program running, then make it greet someone by name.

1. Install Guion. Treat `{{ROOT}}/home` as your home directory: set `HOME` to it for every
   command you run, and install nothing anywhere else.
2. Run the hello-world program the website shows. See what it prints.
3. Change the program so it prints exactly `Hello, Ada!`, and run it again. Keep your work
   under `{{ROOT}}/work`.

## What you must hand back

1. The steps you took, in order. For each step, where you learned it: a website page and
   the passage, or a path inside the download, or "guessed".
2. Every place the website left you not knowing what to do next, or sent you the wrong way.
   Say "none" only if there were none.
3. The final program's source and the output of running it.
