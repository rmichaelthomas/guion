# T1 — serve two clients at once

`src/main.gu` is an HTTP server. It works, and it serves one client at a time: a
client that opens a connection and sends its request slowly blocks every other
client for as long as it takes.

Change the program so two clients are served at the same time. Keep the port at
8090.

## What you must hand back

1. The changed program.
2. A check that proves it: something a person can run that fails on the program you
   started with and passes on the program you wrote. A check that also passes
   against the original proves nothing.
3. A short paragraph on the limit of your fix — what it does not give you.

Stop when those three things exist. Do not improve the server beyond them.
