# H-1.4 receipts — website track (T6). Append-only.

Subjects: Sonnet-class subagents. Blinding by instruction only: every subject's harness spilled oversized tool output to a file outside the root (none opened). Not people.

## Pilot, runs 1-3: INVALID FOR THE INDENTATION FINDING
My text export of the site collapsed the indentation inside code blocks, so subjects saw the hello-world body indented by one space. Runs 1 and 2 hit E_INDENT_WIDTH and reported it as a site problem; run 3 reported it too. That was the runner's defect, not the site's (the real page keeps its 4 spaces). Fixed in run.py (code blocks keep whitespace). The other findings in these runs match the clean runs below. Kept as history; not counted in the campaign line.
T6 run 1: output correct (Hello, Ada!), wrong turns 0 (not counted), site gaps: install steps, how to run a file, PATH, archive contents; plus the invalid indentation one.
T6 run 2: output correct, wrong turns 0 (not counted), same, plus no string-joining example.
T6 run 3: output correct, wrong turns 0 (not counted), same.
