# Changelog

Changes are recorded here as the project moves toward its first release. No public Guion release has been published.

## Unreleased — pre-release development

- Artifact format 64: `csv_read_columns(path, kinds)` reads a CSV file straight into typed columns (`record CsvColumn` in `std:csv`), with kinds inferred or fixed by name, quoted empty text kept in text columns, and the file streamed instead of checked against `max_file_bytes`. `csv_open`, `csv_next` and `file_open_lines` no longer check the whole file against `max_file_bytes` either (each record is still held to it); `read_text` and other whole-file reads keep the check. `R_ALLOCATION_LIMIT` messages now name `allocation_limit_bytes` under `[runtime]` as the setting to raise.
- Artifact format 63: array kernels for gathering, grouping and joining (`array_take`, `array_factorize`, `array_first_index`, `array_count_by`, `array_sum_by`, `array_min_by`, `array_max_by`, `array_mean_by`, `array_join_index`), compiled identically by both compilers. A first-party `frames` library in `packages/frames` builds data frames on them: `i64`, `f64`, `bool` and dictionary-encoded `text` columns with missing values; CSV and JSONL reading, CSV writing and a printed table; select, filter, multi-key stable sort, group-by with `sum`, `mean`, `min`, `max` and `count`, and inner and left joins. It is not published to the registry.
- Artifact format 62: native n-dimensional arrays, `Array[e]` over `i8` to `u64`, `f32`, `f64` and `bool`, with checked conversion and integer overflow, NumPy-style broadcasting arithmetic, comparisons, float math, exact integer reductions, axis reductions, stable sorting, `dot`/`matmul`, ranges, `linspace`, and seeded random and normal arrays that continue the `std:random` stream. `set a = array_set(a, i, v)` updates a local in place. Both compilers accept, reject and compile array programs identically. Array functions run in the VM; the machine-code tier compiles the functions around them.
- Artifact format 61: `std:random` runs as machine code with unchanged sequences (`random_next_i64` added; ranges wider than 2^64 raise `R_RANDOM_RANGE`), and `std:net` adds mutual TLS (`tls_connect_with_identity`, `tls_accept_verified`). Chained text appends to a local are linear; functions returning `Unit` and functions using `assert` compile natively. `guion update` moves registry packages within their recorded range, `guion token rotate|revoke` and matching registry endpoints retire publisher tokens, and library checks require hosts in URL literals to be declared. `fs_remove` and `fs_rename` act on symlinks themselves, and writing through a dangling symlink is refused (it could create a file outside the granted root).
- Command-line programs are limited by memory in use (256 MiB by default) instead of cumulative allocation, and have no default instruction limit; embedders keep both bounds. Records that hold scalar-only records now run as machine code, and native code no longer lets a record kept from an earlier loop iteration be overwritten by a later call. The registry signs its log with ed25519 and the client verifies it (the default registry's key is built in), `guion check` and `guion inspect` say when a program can write files, and precompiled `.gub` attachments are deferred.
- Added a register form of the VM, translated per function on first call, which falls back exactly to the stack interpreter. `Map` is now a seeded hash table with shared keys; observable order stays sorted by key. `guion run` compiles only functions reachable from `main`, and the VM's local fuel reservation is 4096 instructions.
- Native functions that fail now keep the output they printed first; previously `print(7)` followed by a failure printed nothing. `print` of `Text` now compiles natively in functions with a loop. `csv_next_row` and `text_parse_integer` run as direct host operations, plain CSV records take a faster path, and the VM reads maps and lists without clones. The VM now polls cancellation at frame entry, loop edges and after host operations, so a cancelled program can finish its current straight-line run of instructions before stopping.
- Shrank the runtime `Value` from 88 to 24 bytes, added integer and clone fast paths to the VM, and made packages profile-guided by default (`GUION_PGO=0` opts out). Allocation limits charge the smaller value size, so a given `allocation_limit_bytes` now holds more values.
- Added format-45 `http_response_text` with bounded checked UTF-8 decoding, plus `std:http.http_response_json` for typed JSON parsing and stable error mapping. Existing HTTP request APIs retain their result types.
- Added format-41 stable integer-key sorting and merging plus `JsonSetLocal` bytecode for alias-safe, copy-on-write local JSON-object updates; added a fast artifact-format assertion audit that runs before long validation gates. Format 42 assigns distinct local-time opcode tags so temporal resolution coexists with those format-41 instructions.
- Added pure `std:time` local-time resolution that reports exact times, daylight-saving gaps, and folds with all candidate instants using bundled tzdata 2026c. Calendar events now preserve local endpoint identity and ambiguity instead of selecting an instant; `guion --version` reports the timezone-data version.
- Renamed active product surfaces from Veritas to Guion: CLI, Cargo packages, source and artifact extensions, project filenames, examples, standard library, compiler seed, and packaging tools.
- Added transition reads for selected legacy Veritas manifests, locks, project state, source files, and existing artifacts.
- Added a Guion-named acceptance-report cohort for nine retained applications; the frozen Veritas evidence remains unchanged.
- Replaced current-facing getting-started, architecture, reference, compatibility, and status documentation; preserved the Veritas-era checkpoints and results as history.
- Added an agent start guide, four runnable recipes, a versioned machine index, and CLI JSON report envelope schemas.
- Full Guion release-matrix, benchmark, evidence-index, and pre-release handoff checks remain open.
