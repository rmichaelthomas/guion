09 / The origin

The reason
before the name.

Guion began with a north-star question: could a new general-purpose language earn a recommendation over Python for real work, through the whole experience of writing, checking, running, delivering and maintaining a program?

The name

Guion, said GUY-on.

The language is named for Guion “Guy” Bluford, the aerospace engineer, Air Force pilot and NASA astronaut who became the first African American to fly in space. The name honours what he did.

It was also chosen for its sound. Said aloud, Guion sounds like the name of a subatomic particle, alongside the muon, the gluon and the quark.

Recorded in docs/namesake.md, from the project's architect and NASA's records.

  4. 3 Nov 2026

    The server speed gate.

    On two kinds of server CPU, Guion took less time than Python on every text, JSON Lines and CSV run, at both sizes. A week earlier it was several times slower on the same kind of work.

    Build 1746d10, artifact format 51, Linux x86_64 and ARM64. Report in evaluation/completion/results/real-task-sprint/2026-11-03-server-speed-gate.md.

  5. 4 Nov 2026

    A package registry, and more machine code.

    Libraries can now be published to and installed from a package registry whose history is signed, and more of a program runs as machine code. Nothing has been published to the registry yet. The second preview build includes the client commands.

    Pull request #35, artifact format 61, the registry Worker deployed with its signing key. Report in evaluation/completion/results/2026-11-04-follow-ups-report.md.

  6. 5 Nov 2026

    Two fixes, and the numbers measured again.

    A change meant to speed up some programs slowed another one down, and a check was missing on the main branch. Both were fixed, and the Mac results on this page were measured again on the fixed build.

    Pull requests 37, 39 and 40; main at commit 484cefd, artifact format 61, macOS ARM64. Report in evaluation/completion/results/2026-11-05-mac-remeasurement/2026-11-05-mac-remeasurement.md.
