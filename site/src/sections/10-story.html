09 / The origin

The reason
before the name.

Guion began with a north-star question: could a new general-purpose language earn a recommendation over Python for real work, through the whole experience of writing, checking, running, delivering and maintaining a program?

The name

Guion, said GUY-on.

The language is named for Guion “Guy” Bluford, the aerospace engineer, Air Force pilot and NASA astronaut who became the first African American to fly in space. The name honours what he did.

It was also chosen for its sound. Said aloud, Guion sounds like the name of a subatomic particle, alongside the muon, the gluon and the quark.

Recorded in docs/namesake.md, from the project's architect and NASA's records.

  4. 3 Nov 2026

    The server speed gate.

    On two kinds of server CPU, Guion took less time than Python on every text, JSON Lines and CSV run, at both sizes. A week earlier it was several times slower on the same kind of work.

    Build 1746d10, artifact format 51, Linux x86_64 and ARM64. Report in evaluation/completion/results/real-task-sprint/2026-11-03-server-speed-gate.md.

  5. 4 Nov 2026

    Libraries can now be published to and installed from a package registry whose history is signed, and more of a program runs as machine code. Nothing has been published to the registry yet. The second preview build includes the client commands.

    Pull request #35, artifact format 61, the registry Worker deployed with its signing key. Report in evaluation/completion/results/2026-11-04-follow-ups-report.md.

    Pull requests 37, 39 and 40; main at commit 484cefd, artifact format 61, macOS ARM64. Report in evaluation/completion/results/2026-11-05-mac-remeasurement/2026-11-05-mac-remeasurement.md.

  7. 5 Nov 2026

    A second preview, with macOS.

  8. 12 Nov 2026

    Guion 0.2.0, the first release that is not a preview.

    Guion 0.2.0 is out for Linux and for Macs with Apple silicon. It has a written policy for what stays compatible between releases, and the package registry now holds its first package, a data-frame library called frames. Guion also has native arrays now. Both are young: in the project's own reports on one Apple M1 Pro, frames finishes five tested CSV workloads before pandas end to end, mostly because pandas takes about 0.26 s to load, but on compute alone reading a large CSV is still about 3 times pandas and array maths is about 1.4 to 2.3 times NumPy's. The Mac build is signed and notarized by Apple.

    Release v0.2.0, artifact formats 14 through 64. Stability policy in docs/stability-policy.md; frames 0.1.0 installs with guion add frames. Linux archives for Debian 12 on ARM64 and x86_64, and a signed, notarized macOS archive, each with a SHA-256 file. Previous previews stay on the release page as history.

  9. 14 Nov 2026

    Guion 0.4.0.

    Guion 0.4.0 is out for Linux and for Macs with Apple silicon. It adds functions you can pass around, more of the standard library (logging, compression, tar archives, YAML, SHA-256 and random bytes), and a web package for building web applications, with sessions, protection against forged requests and templates that escape their output. The Mac build is signed and notarized by Apple.

    Release v0.4.0 (it includes 0.3.0), artifact formats 14 through 73. web 0.1.0 installs with guion add web --approve-capabilities. Two deliberate breaks from 0.2.0 are listed in the changelog: SQLite is reported as file access, and a project approves no package capabilities until it says so. Linux archives for Debian 12 on ARM64 and x86_64, and a signed, notarized macOS archive, each with a SHA-256 file.

  10. 14 Nov 2026

    Guion 0.5.0: closures, enums, generics, an editor, and two more platforms.

    Functions can now carry values from the code around them, a choice can be one of several named variants that the compiler checks you handled, and one function can work for several types. There is an editor server and an interactive prompt, and a program can be recorded once and replayed later without touching files or the network. A web handler that crashes now gets an error answer and the server keeps going. A naive recursive Fibonacci(32) took a median of 49 ms in Guion and 269 ms in Python on one Apple Silicon Mac, over five runs; that is one small program, not general speed.

    Release v0.5.0, artifact format 74. try_map_list is a per-item fault boundary; guion run --record/--replay keeps credential headers off tapes. Intel Mac (signed, notarized) and Windows (unsigned) archives were built and smoke-tested on GitHub runners, not run through the full test suite. brew install rmichaelthomas/guion/guion and a one-line installer script are new. web 0.1.1 is on the registry.

  11. 14 Nov 2026

    Guion 0.6.0: number-keyed maps, generic records, and more in the browser.

    A map can now be keyed by whole numbers and walked in numeric order, a record can be written once for several types, and the in-browser playground now runs the list helpers and sorts. A recorded run that fans out across several workers can be replayed with any number of workers. No performance numbers on this page were re-measured for this release.

    Release v0.6.0, artifact format 75. Map[Int, T], generic records by compile-time monomorphisation, the browser VM runs map_list, filter_list, fold_list, any_list, all_list and every sort (not parallel_map), tape lanes per parallel_map item. web 0.1.2 is on the registry.
