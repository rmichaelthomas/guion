01 / Try it

Run one.
Right here.

Pick a program and press Run. Your browser compiles it, then runs it on the same virtual machine Guion uses everywhere else.

Compiles one file in guion_compiler.wasm, then runs the artifact on guion_vm.wasm through browser ABI 1.0. Neither module is fetched until you press Run.

Limits in this playground

Outputat most 65,536 bytes captured


Artifactat most 1 MiB


Hostno capabilities granted; file, network, database, clock and process operations return R_HOST_UNSUPPORTED
