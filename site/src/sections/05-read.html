fn main() -> Int is the entry point and its return value is the exit status. let binds immutably; print writes one line. {{sample-facts:hello}}

option.gu

{{sample-code:option}}

Prints {{sample-out:option}}

A function that might have no answer says so in its type, and returns None when it has none. The program checks before it uses the answer, so the empty case is out in the open.

Option[Int] is built with Some(value) or None; is_some tests for presence and unwrap is for after that test. Only the present value prints. {{sample-facts:option}}

records.gu

{{sample-code:records}}

Prints {{sample-out:records}}

A record is a named bundle of typed fields. This one moves a point two across and one down, then checks the result against what it should be.

record Point has two Int fields; translate returns a new Point; assert(finish == Point(5, 3)) compares the result to the expected record. {{sample-facts:records}}

enums.gu

{{sample-code:enums}}

Prints {{sample-out:enums}}

A value can be one of several named shapes, each carrying its own data. When you pick the shape apart with match, Guion makes you cover every one. Leave one out and it refuses to build, naming the missing case.

enum Shape has three variants; match shape: must name each (E_MATCH_MISSING_VARIANT otherwise); a variant is built like a call, Circle(2). Variants with no data, such as Dot, are written bare. The Forget a variant example shows the refusal. {{sample-facts:enums}}

closures.gu

{{sample-code:closures}}

Prints {{sample-out:closures}}

A small function written inside another one can use the values around it. Here add_bonus remembers bonus and adds it every time you call it.

A nested fn captures the names it uses from the enclosing function, by value, at the point it is declared (artifact format 74, Op::MakeClosure). In the command-line runtime it can be passed to map_list, filter_list and the other list functions, but not to sort or parallel_map. {{sample-facts:closures}}

generics.gu

{{sample-code:generics}}

Prints {{sample-out:generics}}

One function can work for many types. first returns the first item of any list: here it is used once on numbers and once on words, and each result keeps its own type.

fn first[T](items: List[T]) -> T declares a type parameter; the compiler infers T at each call and builds one instance per type it sees (up to 512 per program). {{sample-facts:generics}}
