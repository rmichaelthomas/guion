Every program starts at main. This one names a greeting, prints it, and returns 0 to say it went fine.

fn main() -> Int is the entry point and its return value is the exit status. let binds immutably; print writes one line. {{sample-facts:hello}}

option.gu

{{sample-code:option}}

Prints {{sample-out:option}}

A function that might have no answer says so in its type, and returns None when it has none. The program checks before it uses the answer, so the empty case is out in the open.

Option[Int] is built with Some(value) or None; is_some tests for presence and unwrap is for after that test. Only the present value prints. {{sample-facts:option}}

records.gu

{{sample-code:records}}

Prints {{sample-out:records}}

A record is a named bundle of typed fields. This one moves a point two across and one down, then checks the result against what it should be.

record Point has two Int fields; translate returns a new Point; assert(finish == Point(5, 3)) compares the result to the expected record. {{sample-facts:records}}
