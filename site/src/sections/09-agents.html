More and more people ask an assistant which language to use. So this site is written to be read by one: every claim, with the conditions it holds under and what it does not tell you, in two plain files.

llms.txt and agents.json carry the same receipts as this page. The project's own agent index is docs/agents/index.json; every --json command below returns a versioned envelope.
