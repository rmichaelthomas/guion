Get started

Install it.
Run your first program.

Four steps. You need a terminal and nothing else: no Rust and no Python.

brew install rmichaelthomas/guion/guion, the one-line installer, or an archive and sh install.sh; add ~/.local/bin to PATH for the last two. No Rust or Python needed.

  1. 1. Install

    On a Mac or Linux with Homebrew:

    brew install rmichaelthomas/guion/guion

    Or with the one-line installer, which checks the download's checksum and puts guion under ~/.local:

    curl -fsSL https://raw.githubusercontent.com/rmichaelthomas/guion/main/distribution/get-guion.sh | sh

    Or download an archive from the v0.9.1 release page: guion-macos-aarch64.tar.gz (Apple silicon), guion-macos-x86_64.tar.gz (Intel Mac), guion-debian-x86_64.tar.gz or guion-debian-aarch64.tar.gz (Linux), or guion-windows-x86_64.zip (Windows; unzip it and add its bin folder to your PATH). Then, on a Mac or Linux:

    tar -xzf guion-macos-aarch64.tar.gz
cd guion-macos-aarch64
sh install.sh

    Use the matching name for another archive. Homebrew and the one-line installer need no further step. The archive installer puts guion under ~/.local; give it a path to choose another place. The Windows build is not signed.

  2. 2. Let your terminal find it

    Homebrew does this for you. After the installer script or an archive, add the install folder to your PATH (put this line in your shell's startup file to keep it), then check it works:

    export PATH="$HOME/.local/bin:$PATH"
guion --version

  3. 3. Run a program

    Save this as hello.gu. Guion indents with four spaces, so keep that. Then run the file:

    fn main() -> Int:
    let greeting = "Hello, Guion!"
    print(greeting)
    return 0
    guion run hello.gu

    Prints Hello, Guion!

  4. 4. Change it

    Make it greet someone by name. Text is joined with +. Save the change and run it again:

    fn main() -> Int:
    let name = "Ada"
    print("Hello, " + name + "!")
    return 0

    Prints Hello, Ada!

    Next: guion new my-app makes a small project with a program, a test and a manifest, and the guides are in the archive under share/guion/docs/. This is the install for Guion itself; guion install in the command table below installs a packed app.
