Get started

Install it.
Run your first program.

Four steps. You need a terminal and nothing else: no Rust and no Python.

Download, unpack, sh install.sh, add ~/.local/bin to PATH. No Rust or Python needed.

  1. 1. Download and install

    Get the archive for your machine from the v0.4.0 release page: guion-macos-aarch64.tar.gz for a Mac with Apple silicon, guion-debian-x86_64.tar.gz or guion-debian-aarch64.tar.gz for Linux. Then, in a terminal:

    tar -xzf guion-macos-aarch64.tar.gz
cd guion-macos-aarch64
sh install.sh

    Use the matching name for a Linux archive. The installer puts guion under ~/.local; give it a path to choose another place.

  2. 2. Let your terminal find it

    Add the install folder to your PATH (put this line in your shell's startup file to keep it), then check it works:

    export PATH="$HOME/.local/bin:$PATH"
guion --version

  3. 3. Run a program

    Save this as hello.gu. Guion indents with four spaces, so keep that. Then run the file:

    fn main() -> Int:
    let greeting = "Hello, Guion!"
    print(greeting)
    return 0
    guion run hello.gu

    Prints Hello, Guion!

  4. 4. Change it

    Make it greet someone by name. Text is joined with +. Save the change and run it again:

    fn main() -> Int:
    let name = "Ada"
    print("Hello, " + name + "!")
    return 0

    Prints Hello, Ada!

    Next: guion new my-app makes a small project with a program, a test and a manifest, and the guides are in the archive under share/guion/docs/. This is the install for Guion itself; guion install in the command table below installs a packed app.
