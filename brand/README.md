# Brand assets

The Guion mark is the website's brandmark: a blue tile turned four degrees, with a white serif `g`. Text in these files is drawn as outlines, so they render the same everywhere without fonts.

| File | Use |
|---|---|
| `mark.svg` | The mark alone: avatars, favicons, small spaces. |
| `mark-512.png`, `mark-180.png` | The mark as PNG; `mark-180.png` is the site's touch icon. |
| `wordmark-light.svg` | Mark and name on light backgrounds. |
| `wordmark-dark.svg` | Mark and name on dark backgrounds. |
| `social-card.svg`, `social-card.png` | The 1280×640 link-preview card used by the website and the GitHub repository. |

The site build copies `mark.svg`, `mark-180.png` and `social-card.png` into the published site.
