# Security policy

Guion is a pre-release project and has no published release support commitment. The default core CLI applies explicit limits and host permissions, but it is not an operating-system sandbox.

## Reporting a vulnerability

Please do not put credentials, exploit details, or unpublished user data in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use that channel. If it is not available, contact the repository owner privately through a channel already known to you. Include the affected commit or build, the steps to reproduce, and the impact you observed.

There is no guaranteed response time or security-fix schedule during pre-release development. Do not test against systems you do not own or have permission to assess.
