# Richards on the 0.5.0 Mac package (2026-11-14)

Every figure below came from one run of the repository's installed-release performance suite (`evaluation/completion/performance/runner.py --installed`) against the signed 0.5.0 Apple Silicon package built from commit `1c30c7d` (artifact format 74). The host was one Apple Silicon Mac running macOS 27 (27.0.1), with CPython 3.14.7. The full report is `2026-11-14-performance-suite.json` beside this file (local paths replaced with placeholders).

## Richards

Starting from source with no compile cache, Guion finished the Richards benchmark in 26.86 ms. CPython took 66.49 ms. The ratio was 0.402 (0.400–0.414). Peak memory was 25.1 MiB for Guion and 18.2 MiB for Python. The run was 15 randomized trials. Free-threaded Python was unavailable on this host.

The suite also measured the same package against CPython on other workloads in the same run (ratio of Guion over Python, uncached source or artifact as the report states): N-body 0.137 from an artifact, Mandelbrot 0.255 from an artifact, text processing 0.491 from an artifact, and a 20,000-row JSON Lines summary 0.559 from an artifact (0.670 at 200,000 rows).
