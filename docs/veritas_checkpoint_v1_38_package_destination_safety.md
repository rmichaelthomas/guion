# Veritas checkpoint v1.38 — package destination safety

Status: implemented and validated in the installed RC61 release.

`veritas package` now checks package destinations with filesystem metadata that does not follow symlinks. An existing dangling symlink is therefore treated as occupied and is left untouched. JSON mode reports the stable `E_PACKAGE_OUTPUT_EXISTS` diagnostic for this case instead of the generic package-failure code. Final publication uses macOS `renameatx_np(RENAME_EXCL)`, so a destination created after preflight cannot be replaced by the staged package.

The CLI acceptance test also packages a project whose source root includes spaces, writes the app bundle under a destination containing spaces and Unicode, verifies the bundle, and launches it while the process working directory is elsewhere. The launcher successfully validates and executes from that path.

The change was test-first: the new dangling-symlink regression failed against the prior implementation with `E_PACKAGE_FAILED`, then passed after the destination check and diagnostic classification were corrected. A second regression confirms exclusive publication fails with `AlreadyExists` and preserves both the competing destination and staged package. Formatting and Clippy with warnings denied passed. The full Rust workspace passed 119 tests, including managed Python integration and all package relocation tests. The installed RC61 release passed the complete 22-test shipped evaluation suite with its pre-provisioned isolated CPython/cache and loopback test server. Distribution packaging also passed installer relocation into a Unicode path, task-ledger and Python-interoperability package verification, and repeated installed Python app launches with identical output. The editable source archive extracted under a Unicode-and-spaces path and compiled all workspace test executables offline.

This closes the existing-destination, dangling-symlink and concurrent-destination replacement cases for the supported macOS target. Release archive path validation and cross-platform publication are not covered. The shipped evaluation is an author-run kit, not an independent task study, so no recommendation advantage is claimed.
