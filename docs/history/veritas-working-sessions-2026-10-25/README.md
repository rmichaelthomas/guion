# Frozen Veritas working sessions

These are the small working-session records from the original Veritas checkout, retained as historical evidence rather than current instructions. The original source commit is an ancestor of Guion `main`.

`source-working-tree.patch` is the final four-file source-edit patch from that checkout. Its SHA-256 is `dbd90210cf9b9750673d44e2968fc61723a05f9a47215e13c55bc4705bc1605c`. Its content is present in the canonical Guion tree; this copy preserves the exact old working-tree delta.

`independent-v3-pre-migration-README.md` preserves the original README before the migration retention note was appended.

`retired-compiled-artifacts.json` lists generated `.vrb` bytes removed with the old checkout. Their hashes identify the old binaries but do not make them recoverable byte for byte. The source and compact evaluation results remain in the repository.
